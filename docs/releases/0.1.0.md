# 0.1.0 release candidate

This candidate fixes the 2026-10-01 review findings. It has not been published.
It requires the stable review dependency train and uses immutable reviewed CI.
The real WordPress/MariaDB concurrency gate is mandatory in QA.

Tag registrations use bounded rows and do not write when unchanged. Purge queues
acknowledge successful work only; retries are at least once. Provider credentials
are authenticated encrypted values with blank-preserving controls. Uninstall
retains settings/data unless an administrator explicitly enables removal.

See side-effects.md for database permissions, overflow intervention, cron and
encryption-key backup/rotation requirements.
